# Расписание СГУ — 111 группа КНиИТ

Готовый адаптивный сайт для дневной 111-й группы факультета компьютерных наук и информационных технологий Саратовского государственного университета.

**Официальный источник:** https://www.sgu.ru/schedule/knt/do/111  
**Официальный календарь недель:** https://www.sgu.ru/schedule/knt

Начальный снимок расписания получен по состоянию на **26.10.2026**. Снимок включён в сайт, чтобы HTML отображался даже без подключения к серверу. Историческая сессия за июнь 2026 года показана отдельно и помечена архивом.

## Как просто посмотреть сайт

Откройте файл `index.html` двойным щелчком в браузере. Или откройте отдельный файл `SGU_111_расписание.html`, поставляемый вместе с архивом.

**Важно:** при запуске с компьютера (`file://`) обновления автоматически не приходят из СГУ: браузер не может безопасно обходить ограничения другого сайта. Будет доступен встроенный снимок и все локальные функции, включая переключение дат, недель и подгрупп.

## Как сделать свой сайт с автоматическими обновлениями — бесплатно

1. Создайте **публичный репозиторий** на GitHub, например `sgu-111` (ветка `main`).
2. Загрузите **все файлы и папки из этого архива** в корень репозитория, включая скрытую папку `.github/workflows`. Не загружайте только ZIP вместо файлов.
3. Откройте репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Откройте **Settings → Actions → General → Workflow permissions** и выберите **Read and write permissions**. Сохраните настройку.
5. Перейдите в **Actions → Синхронизация расписания СГУ → Run workflow** (если автоматический старт ещё не произошёл).
6. После успешного развёртывания в настройках **Pages** появится адрес вида `https://USERNAME.github.io/sgu-111/`.

После установки GitHub Actions будет запускать скрипт `scripts/update.py` **раз в 3 часа** и проверять официальную страницу СГУ. Если содержание отличается, данные `data/schedule.json` переписываются, а сайт повторно публикуется. Если информация не менялась, перезапись не требуется. **Запуск по расписанию может задерживаться**, а GitHub или сайт университета могут временно быть недоступны: изменения не гарантированы мгновенно. Открытая вкладка сайта заново запрашивает опубликованные данные раз в 15 минут. Кнопка ↻ проверяет данные на **вашем опубликованном сайте**, а не напрямую обходит ограничения СГУ.

При ошибке загрузки или разбора HTML предыдущая проверенная версия **сохраняется**, а в Actions появляется предупреждение. Это защищает от пустого расписания. Если университет сильно изменит HTML, парсер `scripts/update.py` придётся адаптировать.

## Удобство новой версии

- **На первом экране:** сколько занятий сегодня и какая пара ближайшая, с временем и местом проведения. Время всегда считается по Саратову.
- **Быстрый выбор дня:** крупные кнопки с количеством занятий; на узком телефоне полоса дней прокручивается горизонтально.
- **Подгруппа сохраняется** в браузере, чтобы видеть только общие и свои занятия. Пока выбраны «Все», сайт показывает пояснение.
- **Минимум лишнего:** пояснения и сведения об автообновлении скрыты в раскрывающихся разделах.
- **Доступно на мобильном:** адаптация даже под 320 пикселей, переключение между днём и неделей, тёмная тема.
- **Если вкладка открыта ночью:** наступление нового дня по саратовскому времени обновляет главную сводку и текущий день (только если пользователь смотрел вчерашний день).

## Что реализовано

- Числитель и знаменатель из официального календаря СГУ; для недели 2–8 ноября 2026 года — **знаменатель**.
- Учитываются занятия обеих недель, только числителя (`Ч`) или только знаменателя (`З`).
- Фильтр **все / 1-я / 2-я / 3-я подгруппы**; общие занятия видны независимо от подгруппы. Фильтр сохраняется в браузере.
- Просмотр **по дням** и **всей недели**, даты с переключением на предыдущую/следующую неделю и «Сегодня».
- Лекции, практики, лабораторные, время, преподаватели, места проведения, отметки смены расписания.
- Отдельный раздел сессии, индикация ближайшего занятия (по времени Саратова UTC+4), тёмная тема.
- Экспорт текущей и следующих трёх недель в календарь `.ics` (на компьютере кнопка «В календарь»).
- Краткая история последних изменений с официального источника при успешной синхронизации.
- Встроенная последняя доступная копия для отсутствия сети.

## Технически

Стек: HTML / CSS / JavaScript, Python 3.12, BeautifulSoup, GitHub Actions и GitHub Pages. Никакого обязательного платного API и отдельного сервера.

Для ручного обновления, при наличии интернета:

```bash
python -m pip install -r requirements.txt
python scripts/update.py
```

Для запуска проверок парсера:

```bash
python tests/test_update.py
```

**Примечание:** университет может внести разовое изменение/замену в другой источник, не отражённый на публичной странице. Проверяйте официальную страницу при важных занятиях и экзаменах. Вне опубликованного факультетом календаря недель чередование подсчитывается по образцу 2026 года и помечается **«Период не подтверждён»**, пока новый календарь не загружен.

**Использование сведений:** источник — Саратовский государственный университет; при размещении содержимого сохранена активная ссылка на официальный сайт.
